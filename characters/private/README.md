# Personagens privadas

Tudo nesta pasta (exceto este arquivo) fica fora do Git. Crie sua personagem aqui:

```text
characters/private/minha-vtuber/
├── character.toml
├── persona.md
└── skin.png        (opcional)
```

E aponte para ela no `.env`: `WAIFU_CHARACTER=minha-vtuber`. A Mente procura primeiro em `private/`.
